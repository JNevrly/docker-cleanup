## Description

Next milestone following the completed MVP, driven by user review of the installed application. Replace wasteful nested cards and tiny fonts with a compact, readable, light-first resizable workspace. Use main-panel pages for review, execution/results and history; reserve dialogs for exceptional confirmations. Add explicit select-all semantics, a discoverable Engine-wide cache cleanup flow, category explanations, navigable inspector links and structured filesystem/process views. Show truthful overall and per-action progress with accessible cancellation. Preserve all existing deletion, volume, protection, reference and daemon-isolation safeguards. Includes browser/native/live regressions, screenshots, updated user guidance and a reproducible Linux package. External buildx support, remote Docker, deep directory scans, backups and unattended cleanup remain outside this milestone. No due date assigned.
