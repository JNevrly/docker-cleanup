## Description

Deliver a Linux-first Tauri 2 desktop app for one local Docker endpoint. Users can discover storage through category and project treemaps, identify assets through explainable project and process evidence, inspect writable-layer changes and mount boundaries, select assets with honest reclaim estimates, review and execute staged deletions or scoped prune operations, and verify results. Volumes require explicit confirmation; bind-mounted host files are never deleted. Unknown usage timestamps and unsupported storage capabilities remain explicit. Release requires automated safety/regression tests and a packaged Linux application with setup documentation. Excludes remote Docker, deep per-directory scans inside container filesystems, automatic cleanup, and mandatory elevated privileges. No delivery date assigned.
