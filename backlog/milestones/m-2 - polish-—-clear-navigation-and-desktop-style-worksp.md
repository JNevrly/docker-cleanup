## Description

Follow-up to the completed m-1 / 0.2.0 release, based on installed-app user feedback. Reduce instructional text, use conventional disabled controls, put breadcrumbs in the treemap heading and make Storage explorer return to All storage. Keep periodic scanning from moving the layout. Hide redundant single-color legends and fit meaningful treemap labels with full-name hover/focus disclosure. Replace sizing sliders with accessible draggable splitters, decouple inspector scrolling from the asset table and refresh the palette toward neutral slate/graphite with restrained blue accents. Preserve readable type, Light/Dark/System preferences, destructive safeguards, selection and intentional Back navigation semantics. Includes regression evidence, updated help and a verified Linux update. Remote Docker, external buildx, deep directory sizing and backup/undo remain outside scope.
